# Bundeli Mart

A responsive storefront showcasing traditional Bundelkhand food.

## Run locally

Serve the `dist` directory with any static HTTP server, or open `dist/index.html` directly in a browser.

## Files

- `dist/index.html`: page content and layout
- `dist/style.css`: responsive styling
- `dist/app.js`: food catalog, category filters, and preview basket
- `dist/thali.jpg`: regional food photograph

## Current scope

Includes 12 dishes, Hindi names, category filtering, and basket quantity controls. Prices are examples. Orders, payments, inventory, and delivery are not connected. Basket state lasts for the current page session.
